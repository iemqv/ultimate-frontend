Как устроен оттиск

Линогравюра

Рисунок вырезают на линолеуме. Валик оставляет краску на выступах, а углубления не печатаются. На бумаге получается зеркальное изображение.

Смотреть пример ↗
Монотипия

Краску наносят на гладкую пластину и переносят на бумагу. Основной оттиск получается один: при повторе на пластине остаётся меньше краски.

Смотреть пример ↗
Шелкография

Краску продавливают ракелем через открытые участки сетки. Для каждого цвета можно подготовить отдельный трафарет и напечатать слои по очереди.

Смотреть пример ↗

Первый оттиск

Попробуйте монотипию дома: для неё не нужен печатный станок.

  1. Нанесите гуашь тонким слоем на гладкий пластиковый лист.
  2. Проведите по краске ватной палочкой, чтобы оставить светлые линии.
  3. Положите сверху бумагу, прижмите ладонью и снимите лист за угол.
