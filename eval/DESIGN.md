# Revision 2: design decisions and acceptance

The first two pairs exposed a gap between choosing a theme and designing a page. Both Mossline pages opened with a split, used a serif headline with italic emphasis, and continued with three plant cards. The skill changed the visitor's task more clearly than the page's structure. This is evidence about those renders, not proof of what caused them.

| Earlier instruction | Failure it admitted | Change and evidence to look for |
| --- | --- | --- |
| Compare two ideas when the direction is open | Two names for the same wireframe pass | Draw competing structures with the same real content. Reject a pair that differs only in skin. The chosen structure must organize the next section and survive narrow screens. |
| Choose a memorable detail | A sticker on an interchangeable page qualifies | Choose something the visitor can examine, use or learn from. Let its dimensions and reading order set the composition. |
| Name the surface job | Classification without consequences; applying marketing novelty everywhere | Specify the first user decision. Preserve an approved composition; for a utility screen compare ways of finding or acting on information instead of hero treatments. |
| Check the browser at the end | A functional page can still be a template; motion can hide bad hierarchy | Compare the render to the winning sketch. Redline a specific mismatch before touching the polish. Check interaction separately. |

## How the five approaches divide the work

Impeccable sets the scope: preserving a good existing screen and replacing a visual world are different jobs. Anthropic proposes and tests spatial alternatives; Taste makes those alternatives use the real offer, source material and crops. Unslop concentrates attention within the chosen structure and diagnoses the render. Apple governs the response to a person's input; it does not pick a marketing aesthetic. This order matters: polishing the first plausible layout before considering another layout makes the first one harder to discard.

The brief overrides every source. Useful captions survive Taste's no-caption default. Neither Taste's required entrances nor Unslop's preferred scene hero is a universal rule. Keep the composition static if motion does not clarify a transition. Preserve meaningful brand colors rather than enforcing a neutral template. No mandatory approval step for an already-authorized prototype, and no nine separate edit/review cycles.

The earlier cinema pair did differ: one version split the opening between blue copy and an image, the other overlaid text on the full-width depot. The Mossline pair had the same font bytes and similar compositions, but different hero photos. Its logs also showed reuse of a Playwright installation in shared `/tmp`; they did not establish that either arm copied the other's design. The new experiment isolates the working filesystem rather than relying on a new current directory.

Scope: skill prose, source credits, and a reusable two-brief evaluation. No new global hooks, generated-asset service, upstream scripts or required frontend framework. The parent owns integration and the final visual comparison. An independent reader checks the diagnosis against the pinned sources and prior experiments.

Acceptance: the installed skill routes new design, refinement and critique differently; adapted Unslop material retains its credit and license. Each iteration uses one open and one constrained brief on different subjects, each submitted once with and once without the frozen skill. Inspect all four pages at the same desktop and phone widths. Record a counterexample as readily as an improvement. Do not adjust the prompt or repair a generated page to improve its result.
